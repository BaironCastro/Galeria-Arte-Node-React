# 🎨 CRUD Galería de Arte

Aplicación completa para la gestión de artistas, obras y exposiciones desarrollada con **Node.js (Express + Sequelize)** en el backend y **React (Vite + Bootstrap + Axios + React Hook Form)** en el frontend.

---

## 🚀 Tecnologías utilizadas

### 🧩 Backend
- Node.js + Express
- Sequelize (ORM)
- MySQL
- Nodemon

### 🎨 Frontend
- React (Vite)
- Axios
- React Hook Form
- React Hot Toast
- Bootstrap 5

---

## ⚙️ Instalación y ejecución

### 🔹 Clonar el repositorio
```bash
git clone https://github.com/TU_USUARIO/TU_REPOSITORIO.git
cd TU_REPOSITORIO


🔹 Backend

cd Backend
npm install
npm run dev

El servidor estará disponible en http://localhost:3001



🔹 Frontend

cd frontend
npm install
npm run dev

El frontend estará disponible en http://localhost:5173
